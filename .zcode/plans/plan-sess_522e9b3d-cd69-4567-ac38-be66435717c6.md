# 移动端全面优化方案

## 现状（390×844 视口实拍 + 代码审查确认）
页面级无横向溢出、正文观感良好；问题集中在导航与细节：
1. **汉堡菜单**（仅内容页）：触发按钮 tap 区仅 19×19px；面板仅 176px 宽、22 条挤在 max-h 500px 内部滚动；4 个分组标题渲染成灰色可点条目（带垃圾桶形状图标，点了没反应）；无当前页高亮；面板定位靠 `offsetSkidding=70` 魔法数；`client:only` 导致按钮水合后才出现
2. **代码块**：remote-db 页长代码行右侧被静默裁切（scrollWidth 444 vs 342），移动端无可见滚动条、无「可横滑」提示
3. **Header**：`bg-opacity-80` 是 Tailwind v4 已移除的语法 → 实际全不透明，`backdrop-blur` 意图失效
4. **首页**：下载按钮固定 `w-40` 内容贴边；文档卡片图标 `text-7xl m-10` 导致移动端单列超长、且没用统一 h-28 图标槽（AGENTS.md 规则）；hero `pb-24` 偏大；文档卡片 `ul` 直接子元素是 `<a>`（无效 HTML）
5. **杂项**：viewport 缺 `initial-scale=1`；上一篇/下一篇按钮高 36px 且 client:only 水合前空白；PageContent 空 nav 死标记；LeftSidebar 查询 `.nav-groups` 的死脚本；`.component-preview` 小屏 padding 4rem 过大；VersionLog 长 URL 无 break-words

## 改动清单

### 1. 移动端抽屉菜单（核心，已确认方案）
- 新建 `src/components/Header/MobileNav.vue` 替换 Header 中的 DropdownNav（后者删除）：
  - 触发按钮 p-2，tap 目标 ≥40px
  - fixed 全屏遮罩 + 左侧滑入面板（宽约 300px、max-w-[85vw]），transform 过渡
  - 按 SIDEBAR 四组渲染：组标题为纯文本小标签（不可点），页面条目高亮当前页（Header 已有 currentPage 传入）
  - 关闭：遮罩点击 / X 按钮 / ESC；打开时锁 body 滚动；点击条目关闭后跳转（保持 window.location.href）
  - 纯 Vue + transition，零新依赖
- Header.astro：触发按钮改挂 MobileNav，`md:hidden` 保留

### 2. Header 玻璃效果修复
- `bg-slate-100 bg-opacity-80` → `bg-slate-100/80`（v4 语法），backdrop-blur-md 真正生效

### 3. 代码块移动端
- `.astro-code` 小屏 padding 0.75rem；为 pre 加细滚动条样式（6px 高、slate 圆角 thumb），让「可横滑」可见

### 4. 首页移动端
- hero：`pb-24` → `pb-16 sm:pb-24`
- 三个按钮：固定 `w-40` → 自适应宽度（min-w + px-6），不再贴边
- 二维码：外层容器限宽 + `[&>svg]:w-44 [&>svg]:h-auto` 响应式
- 文档卡片：图标改用与友链一致的统一图标槽（`h-28` 居中槽 + text-6xl），移动端卡片明显变矮，标题基线不动（符合 friendship-links 规则）；`ul>a` 修正为 `li` 包裹

### 5. 杂项修复
- viewport meta 加 `initial-scale=1`
- ContentLink：按钮增高至约 40px tap 高度；`client:only` → `client:load` 尝试 SSR 消除水合前空白（若水合报错则回退）
- PageContent 删空 nav；LeftSidebar 删 `.nav-groups` 死脚本
- `.component-preview` 小屏 padding 1.5rem；VersionLog 加 break-words

- 768px 边界检查（抽屉消失、桌面侧栏出现）；1280px 桌面回归确保上轮成果不回退
